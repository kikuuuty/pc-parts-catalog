# Data attribution

Contains information from [BuildCores OpenDB](https://github.com/buildcores/buildcores-open-db),
which is made available under the [ODC Attribution License](https://opendatacommons.org/licenses/by/1-0/).

Source database: https://github.com/buildcores/buildcores-open-db

License: Open Data Commons Attribution License (ODC-By) v1.0

License text: https://opendatacommons.org/licenses/by/1-0/

This project transforms the source into normalized catalog records, typed specifications,
product identifiers and search indexes. BuildCores-derived information remains attributed
to BuildCores OpenDB. Local enrichment is stored separately with its own provenance.

Unmodified upstream README and LICENSE.txt are retained by the fetch/inspection process
in the snapshot and in `.cache/notices/<commit>/`. Database exports include attribution
and the license URI in `sources`. Preserve these notices when distributing derived data.
